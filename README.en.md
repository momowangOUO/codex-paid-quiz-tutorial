> A practical path from idea to GitHub, Zeabur, Paddle checkout, and automatic unlocks.

- This tutorial focuses on building a real paid website, not explaining theory in isolation.
- The order matters: build a working site first, deploy it to Zeabur to get an HTTPS domain, then use that domain for Paddle website approval and checkout.
- If you are new, follow the chapters in order and ask Codex to break down, implement, and verify each step.

## What You Will Build

- Create a usable free quiz and result preview.
- Store order status on the backend instead of trusting URL flags.
- Deploy to Zeabur and get a Paddle-verifiable HTTPS domain.
- Use Paddle Checkout and webhooks to unlock paid content automatically.
- Run a pre-launch checklist so secrets stay private.
