> A practical path from zero to GitHub, Zeabur, Paddle Checkout, and automatic paid-content unlocks.

- This is not an abstract architecture course; it is an implementation guide.
- Recommended order: build a working site, push to GitHub, deploy to Zeabur for an HTTPS domain, then connect Paddle.
- If you are new, follow the chapters in order and let Codex break down, implement, and verify each step.

## What you will build

- A usable free quiz and result preview.
- A backend-owned payment status and unlock flow.
- A Zeabur-hosted HTTPS website that Paddle can verify.
- Paddle Checkout plus webhook-based automatic unlocks.
