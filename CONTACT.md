# Contact and Collaboration

For private collaboration, case sharing, translation help, or feedback that should not be public, please use the form below:

[Open the collaboration form](https://docs.google.com/forms/d/e/1FAIpQLSet3g2cL32ZElYICNwvxaq27R0pxqyoHw2AK5bQHjDzNQwlUg/viewform)

Public documentation corrections can still be opened as GitHub issues, but please do not include private contact details, API keys, account images, payment logs, webhook secrets, or user data.

## What the form is for

- Collaboration ideas.
- Tutorial translation help.
- Deployment notes from Zeabur, Paddle, or similar platforms.
- Case studies from people building paid websites with Codex.
- Corrections that require private context.

## Form maintenance

The helper script is in [tools/create-google-contact-form.gs](tools/create-google-contact-form.gs). It can be pasted into Google Apps Script if the form needs to be recreated.
