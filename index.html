What You Build

01

先让 Codex 建出网站

02

先部署 Zeabur

03

再接 Paddle 收款

用 Zeabur 域名完成网站验证、default payment link、webhook 和 checkout。

Beginner First

不先讲一堆原理，先把东西做出来

教程会用“你该点哪里、填什么、贴什么提示词、怎么验收”的方式推进。你会先做最小版本，再部署 Zeabur 拿域名，再接 Paddle，最后才优化转化率和视觉。

你负责说明产品、测试网页、贴错误日志
Codex 负责写前端、写后端、修 bug、补配置
Paddle 负责付款页面、交易结果、webhook 通知
Zeabur 负责从 GitHub 部署网站、提供 HTTPS 域名
