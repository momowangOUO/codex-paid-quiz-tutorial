## Chapter Structure

Every language folder follows the same seven-chapter structure:

1. Product flow design.
2. Codex-assisted build workflow.
3. Uploading the project to GitHub.
4. Deploying to Zeabur and preparing a verifiable domain.
5. Connecting Paddle payment and automatic unlock.
6. Copyable Codex prompt templates.
7. Pre-launch checklist.

When you update a chapter, keep the corresponding language index in sync. If a translation is not ready yet, mark that clearly in the pull request instead of leaving readers with a silent mismatch.
