# 01. 產品與流程設計

先把產品流程想清楚，再接付款。目標是讓使用者願意完成測驗，並理解完整報告值得解鎖。

## 最小可收費版本

- 免費入口：完成測驗，看到有專業感的導言版結果。
- 付費內容：完整報告、職涯方向、行動路線與可儲存報告。
- 解鎖方式：付款後由後端確認，自動解鎖頁面。

## 推薦流程

1. 首頁說明測驗價值，不要一開始就強調收費。
2. 使用者完成題目，系統產生 reportId。
3. 結果頁提供可信任的免費導言。
4. 使用者進入 Paddle Checkout。
5. Paddle webhook 通知後端。
6. 後端標記已付款，前端自動顯示完整報告。

## 給 Codex 的提示詞

```text
請設計一個可收費的測驗網站流程：免費作答、免費導言版結果、付款後自動解鎖完整報告。請列出頁面、API、資料模型和測試情境。
```
