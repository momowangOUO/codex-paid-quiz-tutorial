# 06. 提示詞範本

## 產品流程

```text
請幫我設計一個付費測驗網站：免費作答、導言版結果、付款後自動解鎖完整報告。請列出頁面、API、資料模型與測試情境。
```

## Paddle 後端

```text
請實作 Paddle provider：建立 transaction、寫入 custom_data、驗證 webhook 簽名，只有 transaction.completed 才解鎖。
```

## 部署檢查

```text
請檢查專案是否適合部署到 Zeabur：PORT、0.0.0.0、npm scripts、/api/health、.gitignore、secret 是否外洩。
```
