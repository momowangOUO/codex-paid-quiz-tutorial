| 順番 | 章 | 完了すること |

## おすすめの読み方

1. まず第 1 章を読み、あなたのプロダクトが一回払いの解放モデルに合うか確認します。
2. 第 2 章から第 4 章は、実際に作りながら進めます。
3. 第 5 章では Webhook と秘密情報の扱いを飛ばさないでください。
4. 第 6 章は、設計、実装、修正、レビューが必要なときにいつでも使えます。
5. 第 7 章は、本番公開前のチェックリストとして使ってください。
