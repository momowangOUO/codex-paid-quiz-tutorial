# 07. Launch checklist

## Website

- Landing page loads.
- Quiz can be completed.
- Preview appears.
- Mobile layout is usable.

## Backend

- `/api/health` returns 200.
- No secret is exposed.
- `/data` volume is mounted.

## Paddle

- Domain is approved.
- Default payment link is set.
- Webhook works in sandbox.
- Mock and free unlock tests are disabled before launch.
