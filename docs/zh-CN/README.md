- 这份教程不是讲抽象原理，而是带你做出一个真的能收款、能自动解锁内容的网站。
- 顺序很重要：先做可运行网站，再部署到 Zeabur 拿到 HTTPS 域名，最后再去 Paddle 申请网站验证与付款。
- 如果你是 0 基础，照着章节走，把每一步交给 Codex 拆任务、改代码、检查结果。
