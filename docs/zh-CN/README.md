这是完整的 Markdown 版教程目录。建议按顺序阅读，因为后面的付款、部署和上线检查会依赖前面已经建立好的产品流程、仓库结构和环境变量设计。

## 章节

| 顺序 | 章节 | 你会完成什么 |
| --- | --- | --- |
| 1 | [产品流程怎么拆](01-product-flow.md) | 把付费网站拆成用户路径、页面、状态、数据和解锁条件。 |
| 2 | [怎么让 Codex 从 0 帮你建站](02-codex-build-workflow.md) | 用明确提示词让 Codex 生成项目骨架，并通过迭代修正。 |
| 3 | [上传到 GitHub](03-upload-to-github.md) | 建仓库、提交代码、排除密钥和本地临时文件。 |
| 4 | [部署到 Zeabur，拿到可验证域名](04-zeabur-deployment.md) | 设置构建命令、启动命令、环境变量和可公开访问的域名。 |
| 5 | [有域名后，再接 Paddle 付款与自动解锁](05-payment-unlock.md) | 连接 Paddle Checkout、Webhook、付款状态查询和报告解锁。 |
| 6 | [可直接复制的 Codex 提示词](06-prompt-templates.md) | 使用完整提示词处理产品设计、开发、排错、安全检查和上线前审阅。 |
| 7 | [上线前检查清单](07-launch-checklist.md) | 核对安全、付款、部署、内容、回滚和用户体验。 |

## 推荐读法

1. 先完整读第 1 章，确认你的产品是不是适合一次性付费解锁。
2. 第 2 到第 4 章可以边读边做，先让网站跑起来，再部署到线上。
3. 第 5 章处理付款时，不要跳过 Webhook 和密钥安全说明。
4. 第 6 章可以在任何阶段复制使用。
5. 第 7 章建议在真实发布前逐项勾选。
