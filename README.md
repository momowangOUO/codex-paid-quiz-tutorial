> 从 0 到上线：用 Codex 做出一个真的能部署、能收款、能自动解锁内容的网站。

- 这不是抽象架构课，而是实作路线。
- 推荐顺序：先做可运行网站，再上传 GitHub，再部署 Zeabur 拿 HTTPS 域名，最后接 Paddle。
- 如果你是 0 基础，照着章节走，把每一步交给 Codex 拆任务、改代码、检查结果。

## 你会实际做出什么

- 一个可体验的免费测验与结果页。
- 一个由后端保存订单状态的解锁流程。
- 一个部署在 Zeabur、可用于 Paddle 网站验证的 HTTPS 网站。
- 一个通过 Paddle Checkout 与 webhook 完成自动解锁的付费流程。
