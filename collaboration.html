Form First

为什么不用 GitHub 私信？

Git 没有私信功能，GitHub 也没有适合陌生访客直接私讯作者的内建机制。Issue 和 Discussion 都是公开页面，适合公开勘误、补充截图、讨论 PR，不适合留下私人联系方式。

01

合作主题走表单

让对方提交称呼、主题、阶段、需要协助的地方，以及自愿留下的回复方式。

02

公开修正走 Issue

教程错字、链接失效、部署截图补充、PR 讨论，可以留在 GitHub 上让其他读者也受益。

03

隐私资料不进仓库

私人微信、邮箱、后台截图、订单资料、API key 和付款账号，都不应该写进公开 GitHub 文件。

Google Form Setup

把 Google 表单链接接到这里

目前按钮还没有真实 Google 表单链接。建立表单后，把公开链接复制出来，替换本页按钮里的 #form-setup 即可。

建议表单字段

  1. 你的称呼或团队名称
  2. 你想交流或合作的主题
  3. 目前进度：想法阶段、开发中、已上线、想优化
  4. 你希望得到什么帮助：技术建议、案例交流、共创、访谈、其他
  5. 可公开查看的网址或 GitHub 仓库，如果有
  6. 你愿意留下的回复方式
  7. 补充说明
表单标题 Codex 付费网站教程｜合作与案例交流
表单说明 请简短说明你想做的产品、目前卡点和希望交流的方向。不要提交 API key、付款后台截图或用户隐私资料。
